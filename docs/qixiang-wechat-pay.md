# 七相微信支付接入

适用于钱包余额充值。商户须已开通七相的微信支付产品。接口以[七相聚合支付开发文档](https://qixiangpay.cn/doc_old.html)为准。

在应用容器的私密环境中设置以下变量。密钥由站主从商户后台取得并在服务端填写。

| 变量 | 用途 |
| --- | --- |
| `QIXIANG_PAY_PID` | 商户 ID |
| `QIXIANG_PAY_KEY` | 商户密钥 |
| `QIXIANG_PAY_ENABLED` | 设为 `true` 开启新下单。默认关闭 |
| `QIXIANG_PAY_ORIGIN` | 网关 HTTPS 根地址。默认 `https://api.payqixiang.cn` |

钱包入口需要站点已确认支付合规条款。异步通知地址为支付回调域名下的 `/api/qixiang/notify`。同步返回地址为站点域名下的 `/api/qixiang/return`。两者均需使用公开可访问的 HTTPS。

服务器通过 `mapi.php` 下单，使用 `wxpay` 和 `jump`。收到异步通知后验证签名，并通过 `api.php?act=order` 查询该笔订单。两次金额均与本地订单一致后，余额、充值记录和符合条件的充值权益一起结算。浏览器返回钱包时可查看订单状态。

如七相显示已支付而本站一直显示待支付，可在管理员的充值记录中使用现有补单操作。服务端会重新向七相查单，确认状态和金额后入账。关闭新下单时保留商户凭据，可继续处理在途订单。

上线后用维护账号完成一笔小额验收，核对七相订单、本站充值订单、钱包余额及重复回调。项目中的本地测试使用模拟网关。
