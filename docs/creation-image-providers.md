# AI 创作：Seedream 与 NovelAI 兼容生图

本次为现有 OpenAI 兼容渠道增加创作中心的模型识别和参数配置，不新增官方原生渠道适配器。

## 接口约定

- 用户在 AI 创作选择 Seedream 或 NovelAI 后，前端向 `/pg/creation/images` 提交对应的 `seedream-image` 或 `novelai-image` 配置。
- 服务端将其转换为标准 JSON 生图请求，沿用 `/v1/images/generations` 转发链路。
- `model` 保留渠道中配置的完整名称，现有渠道模型映射仍由原转发层处理，不将不同模型互相替换。
- 请求包含 `model`、`prompt`、`n: 1`、`size`、`response_format: "b64_json"`。
- 响应沿用 OpenAI 图片 JSON：`data[].b64_json` 或 `data[].url`。结果经过现有大小、文件类型、URL 安全与归属校验后归档。
- 本次不处理 NovelAI 原生 `input/parameters` 请求或 ZIP 响应，也不把 OpenAI 兼容渠道配置为火山方舟原生地址。原生接口需要独立、经过验证的适配。

## 模型发现与权限

- 自动识别名称中的 `seedream-`、`novelai-v`，以及以 `nai-diffusion-` 开头的图片模型，大小写不敏感，保留中文前缀。
- 为其补上 `image-generation` 能力；不将豆包文本模型、Seedance 视频模型或 NovelAI 文本模型标为图片模型。
- 创作列表继续取用户可用分组、有效渠道与定价分组的交集；提交时仍由服务端验证模型、协议和分组。
- 模型价格、渠道密钥、启停和分组权限仍需在后台正确配置。本次代码不修改这些生产设置。

## 首版选项与边界

| 配置 | 提供的像素尺寸 | 数量 | 参考图 |
| --- | --- | --- | --- |
| Seedream 兼容生图 | 2048×2048、2304×1728、1728×2304 | 每次 1 张 | 不启用 |
| NovelAI 兼容生图 | 1024×1024、1216×832、832×1216 | 每次 1 张 | 不启用 |

以上是本站兼容请求的受限预设，不代表已经验证每个上游别名支持全部尺寸。发布前应以实际配置的上游做正常内容生成验证；若上游的参数契约不同，需要依据其文档调整，不能据品牌名猜测原生协议。

不显示未经确认的质量档位、额外宽高比或参考图能力。后端同时限制数量和尺寸、拒绝参考图及冲突参数，不能只靠前端禁用。旧客户端以 `openai-image` 提交这两类模型时会先归一化为对应配置，再经过相同校验。

## 计费与发布

沿用原生图预扣、实际结果结算、失败处理、日志和资产保留流程；无数据库结构变更，不新建独立计费路径。GPT Image、Imagen、Gemini 的配置保持原有分支。

本地测试使用风景提示词与隔离数据库，不使用生产密钥、不请求真实付费生图。本次未发布生产镜像。
